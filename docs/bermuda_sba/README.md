## 主な改正の要点

- 施行日: **2024年3月31日**（経過措置・グランドファザリングあり）
- SBA を用いる場合の流動性リスク管理プログラム策定義務化
- 従来の Base Lapse Adjustment (BLA) を **Lapse Cost (LapC)** に改称し、解約可能商品の取扱を厳格化
- デフォルト・ダウングレードコストの算定方法の整備
- モデルガバナンス・バリデーション要件の強化
