# 04 — 総括・前提・限界

## 1. 一行で言うと

> **「販売価格+10%・人件費+20%の一律強制」は、平均的には実質賃金を約+9%
> 押し上げる一方、労働分配率50%を損益分岐点として企業を大企業（増益）と
> 中小企業（赤字化）に二極分化させ、現預金中心の家計（特に高齢者）から
> 労働者・政府へ富を移す、大規模な"再分配＋一回限り10%インフレ"政策**。
> 成長を生む政策ではなく、勝者と敗者を制度的に作り替える政策。

## 2. 5つの核心的発見

1. **損益分岐点は労働分配率50%**（閉鎖経済）。`Δπ = 0.1×付加価値×(1−2s)`。
   全社一律ゆえ仕入れも+10%になり、"丸儲け"の直感は誤り。
2. **大企業（分配率38〜55%）は横ばい〜増益、中小（70〜79%）は大幅減益・赤字化**。
   結果は s だけで決まり、規模間で符号が逆転する。
3. **公定価格セクター（医療・介護・保育・公共交通）が最悪ケース**。
   値上げ不可・賃上げのみ強制で `Δπ=−0.2w` が確定。構造的赤字。
4. **家計は世代分断**。現役労働者は実質+9%だが、現預金1,134兆円を持つ
   高齢者・年金生活者は実質約110兆円が目減り。
5. **政府が最大の受益者**。名目税収が1割前後自然増、債務1,129兆円・対GDP比
   202%超がインフレで実質圧縮（"インフレ税"）。ただし金利上昇が中長期で相殺。

## 3. 結果を左右する決定的前提（ここが崩れると結論が変わる）

| 前提 | 崩れた場合 |
|---|---|
| **「+10%値上げが本当に全社で通る」** | 現実の人件費転嫁率は約5割。通らなければ中小はさらに悪化（最重要） |
| **数量・需要が一定** | +10%値上げで数量減 → 売上ダウンが利益をさらに圧迫 |
| **為替・海外価格が不変** | 円安/円高反応で輸出入の損得が変動 |
| **金融政策が反応しない** | 日銀利上げ → 国債利払い増・景気抑制で全体を下押し |
| **賃上げ+20%が全員に実現** | 雇用調整（解雇・廃業）で平均賃金は上がっても総雇用所得は減りうる |
| **資本ストック・債務が名目固定** | 設備更新・借換が進めば固定費前提が崩れる |

## 4. データ・手法の限界（誠実な開示）

- 数値は `WebSearch` による**公的統計の集約サマリ**（2026-05-29取得）。財務省・
  内閣府・日銀原典への直接アクセスは環境のネットワーク制約で一部ブロックされ、
  **規模別・業種別の付加価値/人件費の絶対額（内訳）までは取得できていない**。
  そのため `02` のマクロ集計は**符号と相対規模の推計**であり、確定金額ではない。
- 労働分配率は統計・定義により水準がぶれる（法人企業統計の「大企業38.1%」と
  「全規模65.1%」など）。本分析は**規模間の大小関係**を頑健な事実として用い、
  水準は幅で扱った。
- 本モデルは**会計恒等式に基づく初期インパクトの比較静学**。一般均衡（価格・
  数量・賃金・為替の同時決定）や動学（期待・投資・人口）は簡略化している。
  精緻化には産業連関表（輸入中間投入比率）と規模別法人企業統計の原データ、
  CGEモデルが必要。

## 5. 政策含意（もしこれを実際にやるなら）

- 一律施策は**最も脆弱な層（中小・公定価格セクター・年金生活者）を直撃**する。
  実施するなら、①公定価格（診療・介護報酬）の同時改定、②中小の価格転嫁の
  法的担保（転嫁拒否規制の強化）、③低所得・年金層へのインフレ補償、が不可欠。
- そうした補完措置なしの「一律強制」は、**増益の大企業と税収増の政府の裏で、
  中小倒産・失業・高齢者の生活困窮**を生む、非対称性の強い政策となる。
