# 国内全企業 価格×1.1・人件費×1.2 一律施策の影響分析

「日本国内の全企業が、製品の販売価格を一律1.1倍、人件費を一律1.2倍にしたら
どうなるか」を、公的統計の実データで推計したシミュレーション・パッケージ。

## 結論（30秒サマリ）

- **核心の公式**：全社一律ゆえ仕入れ（中間投入）も+10%になる。利益変化は
  `Δπ = 0.1 × 付加価値 × (1 − 2s)`（s＝労働分配率）。
  → **損益分岐点は労働分配率50%**。50%未満なら増益、超なら減益。
- **企業の二極化**：大企業（s≈38〜55%）は横ばい〜**増益**、中小（s≈70〜79%）は
  **大幅減益・赤字化**。医療・介護等の**公定価格セクターは値上げ不可で最悪**。
- **家計**：現役労働者は実質賃金**約+9%**だが、現預金1,134兆円を持つ高齢者・
  年金生活者は**実質約110兆円が目減り**（世代間の逆進的再分配）。
- **政府**：名目税収が**1割前後の自然増**、債務1,129兆円・対GDP比202%超が
  インフレで**実質圧縮**（最大の受益者。ただし金利上昇が中長期で相殺）。
- **本質**：成長政策ではなく、**預金者・高齢者・中小企業 → 労働者・大企業・
  政府**への大規模な富の再分配＋一回限り約10%インフレ。

## データの注意

数値は `WebSearch` による公的統計の**集約サマリ**（2026-05-29取得）。原典への
直接アクセスが環境制約で一部ブロックされたため、規模別・業種別の絶対額内訳は
未取得で、マクロ集計は**符号と相対規模の推計**。利用前に原典での再確認を推奨
（`05_sources.md`）。本モデルは会計恒等式に基づく**比較静学（初期インパクト）**
であり、一般均衡・動学効果は簡略化している。
