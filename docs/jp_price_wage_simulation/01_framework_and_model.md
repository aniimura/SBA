# 01 — 分析枠組みと会計モデル

## 0. 問いの定義

> **国内の全企業が一律に、製品販売価格を ×1.1（+10%）、人件費を ×1.2（+20%）に
> したら何が起きるか。**

二つの前提が決定的に重要：

1. **「全社一律」** — 1社だけの値上げではない。よって**自社の仕入れ（他社の
   製品）も同時に+10%になる**。「売値だけ上げて原価据え置き」という素朴な
   "丸儲け"の直感は成立しない。付加価値ベースで考えねばならない。
2. **数量・FXは短期固定**（初期インパクトの分析）。数量の需要反応や為替・
   金融政策の反応は第2ラウンド効果として `03` で扱う。

## 1. 企業1社の損益分解

売上を 100 に基準化し、コストを分解する：

| 項目 | 記号 | 政策後の倍率 | 理由 |
|---|---|---|---|
| 売上高 | 100 | **×1.1** | 自社の値上げ |
| 国内からの仕入れ（中間投入） | m | **×1.1** | 仕入先も全社一律で値上げ |
| 輸入中間投入 | n | **×1.0** | 海外価格・為替不変 → 据え置き |
| 人件費 | w | **×1.2** | 政策による賃上げ |
| その他固定費（減価償却・賃借料・支払利息・租税公課） | f | **×1.0** | 既存資本・既存債務は名目固定（短期） |
| 利益 | π = 100−m−n−w−f | — | 残差 |

政策後の利益変化：

```
Δπ = (110 − 1.1m − n − 1.2w − f) − (100 − m − n − w − f)
   = 10 − 0.1m − 0.2w
```

## 2. 付加価値ベースへの書き換え（核心の公式）

付加価値 **VA = 売上 − 全中間投入 = 100 − m − n**、労働分配率 **s = w / VA**。
`Δπ = 10 − 0.1m − 0.2w` を VA で書き直すと（導出は下注）：

```
Δπ = 0.1 · VA · (1 − 2s) + 0.1 · n
```

> 導出：10 = 0.1×100 = 0.1(VA + m + n)。代入して
> Δπ = 0.1VA + 0.1m + 0.1n − 0.1m − 0.2w = 0.1VA + 0.1n − 0.2(s·VA)
> = 0.1·VA·(1 − 2s) + 0.1n。

### 【最重要の結論】損益分岐点は「労働分配率 50%」

輸入を無視（n=0、閉鎖経済）すると：

```
Δπ = 0.1 · VA · (1 − 2s)
```

| 労働分配率 s | Δπ の符号 | 意味 |
|---|---|---|
| **s < 50%** | **＋（利益増）** | 値上げの取り分が賃上げ負担を上回る |
| **s = 50%** | **0（不変）** | ちょうど均衡 |
| **s > 50%** | **−（利益減）** | 賃上げ負担が値上げの取り分を食いつぶす |

直感：賃上げは「人件費（=分配率 s の部分）に+20%」。値上げは「付加価値全体に
実質+10%」。**人件費が付加価値の半分（50%）を超えると、20%×(>0.5) > 10%×1 と
なり、賃上げ負担が値上げ益を上回る。**

### 輸入の効果（n>0）

輸入中間投入は据え置きなので、`+0.1n` の純益が乗る（売値は上がるが輸入原価は
不変）。これは損益分岐点を**50%より少し上に押し上げる**＝企業にやや有利に働く。
ただしこれは交易条件を通じた海外からの一時的な所得移転であり、為替の円高/円安
反応や輸入競合圧力で相殺されうる（`03`）。日本の粗産出に占める輸入中間投入は
概ね1〜2割と見られるが、確たる最新値は未取得のため本分析では**主結果を閉鎖経済
（50%基準）で示し、輸入は「企業にやや有利方向の感応度」として併記**する。

## 3. なぜ規模・業種で結果が割れるのか

公式 `Δπ = 0.1·VA·(1−2s)` は、**結果が労働分配率 s だけで決まる**ことを示す。
そして s は規模・業種で大きく異なる（`data/00_collected_data.md`）：

- **大企業**：s ≈ 38〜55% → **50%前後〜以下** → 利益は**横ばい〜増加**
- **中堅企業**：s ≈ 65% → 50%超 → 利益**減少（中程度）**
- **中小企業**：s ≈ 70〜79% → 50%を大きく超 → 利益**大幅減・赤字転落も**
- 業種別では、**労働集約的なサービス業・飲食・建設・介護**（高 s）が打撃大、
  **卸売（低 s ≈ 13〜16%）や資本集約型**は相対的に有利。
