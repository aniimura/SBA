# 日本の新ソルベンシー規制（経済価値ベースのソルベンシー規制）関連資料

金融庁が公表している、経済価値ベースのソルベンシー規制（ESR 規制）に関する
公式文書のインデックス。

- IAIS の **ICS（保険資本基準）採択**（2024年12月）を受けて、金融庁は
  保険業法施行規則改正および第1の柱に関する告示を策定。
- **公布日: 2025年7月23日 / 適用日: 2026年（令和8年）3月31日**

すべて公開 PDF。`../../scripts/download.sh` で一括取得できる。
