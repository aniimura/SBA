# 03 — マクロ経済・家計・政府への波及

`01`〜`02` の企業レベル分析を、経済全体（マクロ）、家計、政府の3主体に拡張する。
数量一定の初期インパクトに加え、第2ラウンドの調整も論じる。

## 1. マクロ経済

### (a) 物価：一律+10%の価格 → ほぼCPI+10%級のインフレ
全企業が販売価格を一律+10%にすれば、**消費者物価は概ね+10%近い段階的上昇**。
日本は1980年代以降経験のない急激なインフレ。日銀の物価目標2%を大きく逸脱する
一回限りの水準シフトだが、賃金+20%が並走するため**賃金・物価スパイラル**に
転化し、一過性で終わらない懸念が強い。

### (b) 名目 vs 実質：名目膨張・実質は賃金次第
- 名目GDP（609兆円）は価格上昇分だけ嵩上げされ、**名目で大きく拡大**。
- 賃金は+20%、物価は+10% → 単純計算で**実質賃金は約+9%**（=1.20/1.10−1）。
  これは**労働者にとっては実質購買力の大幅改善**を意味する。
- ただしこれは「+20%賃上げが本当に全員に実現し」「+10%値上げで雇用が維持される」
  場合の話。下記(c)の雇用調整が入ると、平均賃金は上がっても**職を失う層**が
  出て、マクロの家計所得は目減りしうる。

### (c) 雇用：高分配率セクターでの調整圧力（最大のリスク）
`02`の通り、中小・労働集約・公定価格セクターは赤字化する。企業の合理的反応は：
1. **雇用削減・採用抑制**（+20%の人件費を維持できない）→ 失業増
2. **廃業・倒産**（特に転嫁不能な公定価格・下請セクター）
3. **省力化投資・自動化前倒し**（労働を資本で代替）
→ 「実質賃金は上がるが雇用が減る」という**インサイダー/アウトサイダー問題**。
恩恵を受けるのは職を保てた人、割を食うのは解雇・廃業に巻き込まれた人。

### (d) 数量・需要反応
+10%の値上げに対し需要は減少（価格弾力性）。とりわけ消費者向け・価格感応的な
小売・飲食で**数量減** → 売上の数量ダウンが`Δπ`をさらに圧迫。一方で実質賃金増が
消費を下支えする面もあり、**ネットの内需は財・サービスにより区々**。

### (e) 対外・金融
- **輸出**：円建てコスト+20%（人件費）だが、輸出価格を+10%に抑えれば
  価格競争力は実は維持〜改善的（為替不変前提）。ただし国内インフレ+10%が
  続けば**購買力平価的には円安圧力**。
- **輸入**：海外価格不変でも国内が+10%高くなる分、相対的に**輸入品が割安化 →
  輸入代替が進み国内生産にマイナス、経常収支にもマイナス**。
- **金融政策**：+10%インフレに対し日銀は**利上げで対応せざるを得ず**、
  国債利払い増（後述)・景気抑制が働く。本政策はマクロ安定化と真っ向衝突する。

## 2. 家計

| 経路 | 影響 | 規模感 |
|---|---|---|
| 労働所得 | 名目+20%、実質約+9%（職があれば） | プラス大 |
| 雇用リスク | 中小・労働集約で失業・廃業リスク | 一部にマイナス大 |
| 物価（生活費） | 約+10%の物価高 | マイナス |
| **金融資産の実質目減り** | 現預金**1,134兆円**が物価+10%で**実質約110兆円が失われる** | **マイナス甚大** |
| 年金・固定給付 | 名目据置なら実質−10% → 高齢者・年金生活者を直撃 | 世代間で逆進的 |

**最大の論点＝現役 vs 引退世代の分断**：賃上げの恩恵は現役労働者に集中する一方、
インフレは**現預金中心の高齢者・年金生活者の実質資産を大きく削る**。家計金融資産
2,230兆円・うち現預金1,134兆円という日本の資産構成（現預金比率約51%）は、
+10%インフレに極めて脆弱。**事実上、預金者から（賃上げを受ける）労働者・
（債務が目減りする）借り手への巨大な所得・富の再分配**が起きる。

## 3. 政府

### (a) 税収：名目インフレで大幅増収
- **消費税**（25.0兆円）：課税ベースが価格×数量。価格+10%で**ほぼ比例増 → +2兆円超**。
- **所得税**（21.2兆円）：名目賃金+20%＋累進構造の**ブラケット・クリープ**で
  **税収弾性値>1の大幅増**（+4〜5兆円規模も）。
- **法人税**（17.9兆円）：大企業増益分は増、中小赤字分は減 → **ネットは小幅増〜中立**。
- → **国の税収75.2兆円は、名目で1割前後の自然増収**が見込める。

### (b) 歳出：インフレ連動で膨張
公務員人件費・年金（マクロ経済スライド）・各種給付・公共調達がインフレ連動で増。
ただし制度上ラグがあり、**短期は税収増が先行 → 財政収支は一時的に改善**しやすい。

### (c) 政府債務：インフレで実質目減り（"インフレ税"）
- 普通国債残高 **約1,129兆円**、債務対GDP比 **約202〜204%**。
- +10%の物価上昇は名目GDPを押し上げ、**債務対GDP比を実質的に押し下げる**
  （資料の試算でインフレ1%あたり対GDP比を相応に低下）。**最大の"勝者"は
  巨額債務を抱える政府**＝家計の預金保有者から政府への「インフレ税」。
- ただし**金利上昇（(e)）で新発債・借換債の利払い費が増大**し、ストックの
  目減り益を中長期では侵食する。

## 4. 主体別の損得まとめ

| 主体 | 損得 | 主因 |
|---|---|---|
| **大企業（低分配率）** | ◎ 得 | 値上げ益＞賃上げ負担、輸入原価据置 |
| **中小企業（高分配率）** | ✕✕ 大損 | 賃上げ負担＞値上げ益、転嫁不能、赤字化 |
| **公定価格セクター（医療・介護等）** | ✕✕✕ 最悪 | 値上げ不可・賃上げのみ強制 |
| **現役労働者（職を保てる層）** | ◎ 得 | 実質賃金 約+9% |
| **失業・廃業に巻き込まれる層** | ✕✕ 大損 | 雇用調整の犠牲 |
| **高齢者・年金生活者・預金者** | ✕✕ 損 | 現預金・固定給付の実質目減り |
| **借り手（住宅ローン等）** | ◯ 得 | 債務の実質目減り（ただし金利上昇に注意） |
| **政府** | ◎ 得 | 名目税収増＋債務の実質圧縮（インフレ税） |

→ 本政策の本質は「成長」ではなく、**価格・賃金を通じた巨大な再分配**：
**預金者・高齢者・中小企業 → 労働者・大企業・政府**への富の移転。
